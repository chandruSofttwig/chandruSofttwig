## Highlight: AndroGPT

A small language model where I wrote every piece myself, to really understand how ChatGPT-style models work.

| | |
|---|---|
| **Size** | 6.4M parameters · 5 layers · 5 attention heads |
| **Data** | 46M tokens of educational web text (FineWeb-Edu) |
| **Training** | 20,000 steps in ~31 minutes on a free Colab GPU |
| **Result** | Validation loss 6.23 → 4.25, writes grammatical, on-topic paragraphs |
